# IntraBraM

**IntraBraM: Learning General Intracranial EEG Representations via Hybrid Pretraining**

IntraBraM is a pretraining framework for intracranial EEG (iEEG). It learns general
representations with a hybrid objective — a contrastive loss between two noisy views
of the same temporal windows, plus a masked reconstruction loss — and ships with a
finetuning / evaluation pipeline for downstream iEEG tasks.

The repository is fully config-driven (YAML) and ships with **random dummy datasets**
so that every stage can be run end-to-end without any private data.

## Installation

We recommend Conda with Python 3.10 (the reference environment uses Python 3.10.19).

```bash
conda create -n intrabram python=3.10 -y
conda activate intrabram

# install the GPU build of torch that matches your CUDA toolkit first, e.g.:
# pip install torch==2.9.0 --index-url https://download.pytorch.org/whl/cu128
pip install -r requirements.txt
```

`requirements.txt` pins the versions of the reference environment
(`torch 2.9.0`, `lightning 2.5.5`, ...). The code currently targets GPU execution;
there is no `--accelerator` switch — pass your GPU ids with `--devices`
(comma separated, e.g. `--devices 0` or `--devices 0,1`).

## Quick start (dummy data)

The pretraining dataset is a random dummy dataset. Pretraining writes an encoder
checkpoint under `checkpoint_dir/{version}-{timestamp}/` (default `./checkpoints`).

```bash
# 1) Pretrain on the built-in dummy dataset (1 epoch, single GPU)
python script/pretrain.py --version intrabram-base --epochs 1 --devices 0
#    -> saves e.g. checkpoints/intrabram-base-<timestamp>/epoch-0.ckpt

# 2) Finetune on the dummy downstream dataset (dependent split, subject 0)
python script/finetune.py --version intrabram-base \
  --checkpoint checkpoints/intrabram-base-<timestamp>/epoch-0.ckpt \
  --dependency dependent --subject 0 --devices 0
#    -> saves e.g. checkpoints/intrabram-base-dummy-dependent-subject-0-<timestamp>/epoch-0.ckpt

# 3) Evaluate the finetuned checkpoint
python script/eval.py \
  --checkpoint checkpoints/intrabram-base-dummy-dependent-subject-0-<timestamp>/epoch-0.ckpt --devices 0
#    -> results/dummy-...csv

# 4) Batch finetune + eval over all folds of an n-fold split
python script/run_experiment.py --version intrabram-base \
  --checkpoint checkpoints/intrabram-base-<timestamp>/epoch-0.ckpt \
  --dependency independent --devices 0
#    -> results/intrabram-base-dummy-independent/<task>-<timestamp>.csv
```

`<timestamp>` is generated by the scripts; list `checkpoints/` to find the exact name.

## Scripts

All scripts read their model architecture from `config/model/`, their training
hyper-parameters from `config/train/`, and the dataset from `config/downstream_dataset/`.
Only `--checkpoint` (the pretrain encoder checkpoint) is mandatory where a backbone is
needed.

### `script/pretrain.py`

Pretrain an IntraBraM encoder.

```bash
python script/pretrain.py --version intrabram-base --devices 0
python script/pretrain.py --version intrabram-small --epochs 1 --batch-size 8 --devices 0
```

| flag | meaning |
|---|---|
| `--version` | `intrabram-{large,mid,base,small}` |
| `--epochs`, `--batch-size`, `--num-workers`, `--seed`, `--devices` | training overrides |
| `--no-reconstruction` / `--no-contrastive` | disable one loss term |

Encoder checkpoints are written by `IntraBraM.save_encoder` to
`checkpoint_dir/{version}-{timestamp}/epoch-n.ckpt` (plus `config.yaml`) each epoch.

### `script/finetune.py`

Finetune a classifier on top of a pretrain encoder checkpoint, for **one split**.

```bash
# dependent: split each subject into train/test; --subject is the subject id
python script/finetune.py --version intrabram-base \
  --checkpoint /path/to/intrabram-base.ckpt \
  --dependency dependent --subject 0 --devices 0

# independent: n-fold over subjects; --fold-idx is in [0, n_fold)
python script/finetune.py --version intrabram-base \
  --checkpoint /path/to/intrabram-base.ckpt \
  --dependency independent --fold-idx 0 --devices 0

# optional flags
#   --dataset-config config/downstream_dataset/<task>_<dependency>.yaml
#   --use-bias            add the subject-adapter bias path
#   --run-dir <dir>       pin the output run directory
```

The checkpoint directory is
`checkpoint_dir/{version}-{task}-{dependency}-{subject-n|fold-n}-{timestamp}/`
containing `config.yaml` and `epoch-n.ckpt` for every epoch.

### `script/eval.py`

Evaluate a finetuned checkpoint. The task / dependency / split are read from the
checkpoint config, so only `--checkpoint` is required.

```bash
python script/eval.py --checkpoint /path/to/finetune-run/epoch-2.ckpt --devices 0
```

Metrics are written to `results/{version}-{task}-{dependency}-split-{n}/<task>-<timestamp>.csv`
(`total_samples`, `accuracy`, `f1_score`, `cohens_kappa`, `auc`).

### `script/run_experiment.py`

Batch finetune + eval over **all** splits of a dataset config, aggregating the metrics.

```bash
# all folds of an n-fold split
python script/run_experiment.py --version intrabram-base \
  --checkpoint /path/to/intrabram-base.ckpt \
  --dependency independent --devices 0

# all subjects of the dependent split
python script/run_experiment.py --version intrabram-base \
  --checkpoint /path/to/intrabram-base.ckpt \
  --dependency dependent --devices 0
```

Each split is run as an isolated `finetune.py` + `eval.py` subprocess (this keeps the
multi-GPU DDP launcher from re-running the orchestration loop). Aggregated metrics go to
`results/{version}-{task}-{dependency}/<task>-<dependency>-<timestamp>.csv`.

## Building your own dataset

Datasets are defined by two abstract base classes. You only implement the raw loading;
the base class enforces the dtypes/shapes the models expect.

### Pretraining dataset — `src/pretrain_dataset/base_dataset.py`

Subclass `BasePretrainDataset` and implement `load_sample` + `__len__`.
`load_sample(idx)` returns a dict with:

| key | shape | dtype |
|---|---|---|
| `eeg` | `(num_channels, segment_len)` | float32 |
| `mask` | `(num_channels,)` | bool (`True` = valid channel) |
| `mni_pos` | `(num_channels, 3)` | float32 (channel MNI coordinates) |

`segment_len` must be a multiple of the model `window_size` (256). `__getitem__` returns
the validated dict; use `DataLoader(..., batch_size=B)` as usual.

```python
from src.pretrain_dataset import BasePretrainDataset

class MyPretrainDataset(BasePretrainDataset):
    def __init__(self, root, **kwargs):
        super().__init__(**kwargs)
        self.root = root
        # build an index of samples here

    def __len__(self):
        return len(self.index)

    def load_sample(self, idx):
        eeg = ...      # np.ndarray (num_channels, segment_len), float
        mask = ...     # np.ndarray (num_channels,), bool
        mni_pos = ...  # np.ndarray (num_channels, 3), float
        return {"eeg": eeg, "mask": mask, "mni_pos": mni_pos}
```

Then swap `DummyPretrainDataset` for your class in `script/pretrain.py`
(`from src.pretrain_dataset import DummyPretrainDataset`).

### Downstream dataset — `src/downstream_dataset/base_dataset.py`

Subclass `BaseDownstreamDataset` and implement `load_sample` + `__len__`, and set
`self.subject_ids` (one integer subject id per sample). `load_sample(idx)` returns a dict
with:

| key | shape | dtype | notes |
|---|---|---|---|
| `eeg` | `(num_channels, segment_len)` | float32 | |
| `mask` | `(num_channels,)` | bool | `True` = valid channel |
| `label` | scalar | int | class label |
| `mni_pos` | `(num_channels, 3)` | float32 | only required when `use_pos=True` |

`__getitem__` then returns a tuple `(eeg, mask, label)` (or `(eeg, mask, label, mni_pos)`),
which is what `FinetuneModel` consumes.

```python
from src.downstream_dataset import BaseDownstreamDataset

class MyDownstreamDataset(BaseDownstreamDataset):
    def __init__(self, root, use_pos=False, **kwargs):
        super().__init__(path_to_dataset=root, use_pos=use_pos, **kwargs)
        # load data/labels and build the subject index
        self.subject_ids = [...]  # one int per sample

    def __len__(self):
        return len(self.labels)

    def load_sample(self, idx):
        sample = {
            "eeg": ...,    # (num_channels, segment_len)
            "mask": ...,   # (num_channels,) bool
            "label": ...,  # int
        }
        if self.use_pos:
            sample["mni_pos"] = ...  # (num_channels, 3)
        return sample
```

Register it in the factory `build_downstream_dataset` in `src/downstream_dataset/__init__.py`,
and add a YAML config under `config/downstream_dataset/` for each split protocol
(`<task>_dependent.yaml`, `<task>_independent.yaml`):

```yaml
task: my_task              # used in checkpoint / result directory names
path_to_dataset: /path/to/data

frequency: 256
segment_t: 3               # segment_len = segment_t * frequency
max_channel_num: 64
overlap: 0.0
use_pos: false
n_cls: 2
seed: 42

# dependent split
train_ratio: 0.8

# independent split (use instead of train_ratio)
# n_fold: 4
```

### Subject splits

`src/downstream_dataset/splits.py` provides the two evaluation protocols:

* `dependent`: each subject is randomly split into train/test (`train_ratio`, `seed`); one
  finetune run per subject (`--subject`).
* `independent`: subjects are divided into `n_fold` folds; fold `k` is the test set and the
  remaining subjects form the train set (`--fold-idx`).

`get_split_ids(dataset, dependency, n_fold)` returns the ids to iterate over (actual
subject ids for `dependent`, `range(n_fold)` for `independent`).

## Configuration

| file | contents |
|---|---|
| `config/model/model.yaml` | `n_dim`, `window_size`, `max_sec`, `depth` per variant |
| `config/model/embedder.yaml` | CNN patch-embedder layers per variant |
| `config/train/pretrain.yaml` | pretraining batch size / epochs / devices / dummy dataset size / loss switches |
| `config/train/finetune.yaml` | finetuning / evaluation epochs / batch size / splits / devices |
| `config/downstream_dataset/*.yaml` | downstream dataset + split parameters |
| `config/path.yaml` | `checkpoint_dir` (root directory for all saved checkpoints) |

---

## Outputs

* **Pretrain checkpoints**: `{checkpoint_dir}/{version}-{timestamp}/` → `config.yaml`, `epoch-n.ckpt`
* **Finetune checkpoints**: `{checkpoint_dir}/{version}-{task}-{dependency}-{subject|fold}-{timestamp}/` → `config.yaml`, `epoch-n.ckpt`
* **Results**: `results/.../…csv` (see the scripts above)

All saving is rank-0-only under DDP, and per-rank test results are gathered before
computing metrics, so multi-GPU runs save once and report metrics over the full test set.
